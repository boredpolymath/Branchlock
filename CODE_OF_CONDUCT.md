# Code of Conduct

Branchlock follows the [Contributor Covenant Code of Conduct, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html).

## Our commitment

We are committed to a welcoming, inclusive, and harassment-free community. Treat everyone with respect, assume good intent, give constructive feedback, and help create a space where contributors can participate safely.

Unacceptable behavior includes harassment, discriminatory or derogatory comments, personal attacks, unwelcome sexual attention, doxxing, and other conduct that would be inappropriate in a professional setting.

## Scope and enforcement

This Code applies in project spaces and whenever someone represents Branchlock publicly. The repository owner may remove, edit, or reject contributions that do not meet these standards.

To report a concern, contact the repository owner privately through GitHub. Reports will be handled promptly, fairly, and with respect for the reporter's privacy.
